# Lingvo AI

> AI English Tutor — Telegram Mini App. Узбекистан.

AI-репетитор английского языка в Telegram. Общайтесь с AI (Gemini 2.0 Flash), получайте исправления ошибок, пополняйте словарь с интервальным повторением и отслеживайте прогресс. Бесплатно: 10 сообщений/день, премиум — безлимит за Telegram Stars.

## Быстрый старт

```bash
# 1. Клонировать и настроить
cp .env.example .env
# заполнить BOT_TOKEN и GEMINI_API_KEY в .env

# 2. Запустить backend
go mod tidy
go run ./cmd/server

# 3. Запустить frontend (отдельный терминал)
cd web && pnpm install && pnpm dev
```

Откройте `http://localhost:5173` и нажмите "Launch" в Telegram Bot.

## Ключевые функции

- **AI-чат** — общение с AI-репетитором, исправление ошибок в реальном времени
- **Streaming** — SSE-поток для мгновенного отображения ответов
- **Словарь** — добавляйте слова, SM-2 интервальное повторение
- **Тест уровня** — 10 вопросов (A1-C1) для определения уровня
- **Прогресс** — статистика, streak, уровень
- **Подписка** — Telegram Stars (300/week, 800/month)
