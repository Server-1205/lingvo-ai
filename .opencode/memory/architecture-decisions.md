## ADR-001: SQLite вместо PostgreSQL

**Дата**: 2026-06-06
**Статус**: Принято

**Контекст**: Нужна простая БД без DevOps для одного сервера. Целевой хостинг — Railway.

**Решение**: SQLite через modernc.org/sqlite (pure Go, без CGO). sqlx для удобных запросов.

**Последствия**: Нет репликации, нет параллельных писателей. Для MAU < 1000 — ок. При росте — миграция на PostgreSQL.

## ADR-002: Gemini 2.0 Flash как основная AI-модель

**Дата**: 2026-06-06
**Статус**: Принято

**Контекст**: Нужна быстрая и дешёвая модель для real-time чата.

**Решение**: Gemini 2.0 Flash (температура 0.4). Fallback: GPT-4o-mini.

**Последствия**: JSON-парсинг ответа обязателен. Промпты должны требовать валидный JSON.

## ADR-003: Telegram Stars для монетизации

**Дата**: 2026-06-06
**Статус**: Принято

**Контекст**: Целевая аудитория — Узбекистан. У многих нет карт, но есть Stars в Telegram.

**Решение**: Telegram Stars (createInvoiceLink). Комиссия ~32%. Реинвестировать Stars в Telegram Ads.

**Последствия**: Не зависит от платежных систем UZ. Нельзя вернуть деньги (no refunds через Stars).

## ADR-004: Long-polling вместо Webhook

**Дата**: 2026-06-06
**Статус**: Принято

**Контекст**: Mini App не требует real-time уведомлений от бота.

**Решение**: go-telegram-bot-api v5 в long-polling режиме.

**Последствия**: Не нужен публичный HTTPS для бота. Больше нагрузка на сервер.
