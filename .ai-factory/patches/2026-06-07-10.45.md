# DeepSeek fallback not working for streaming; i18n interpolation syntax

**Date:** 2026-06-07 10:45
**Files:** internal/ai/gemini.go, web/src/locales/uz.json, web/src/locales/ru.json, internal/bot/handlers.go, internal/bot/bot.go, cmd/server/main.go, .env
**Severity:** high

## Problem

1. Чат не работал — Gemini возвращал 429 (quota exceeded), а fallback (DeepSeek) не обрабатывал ошибку в стриминговом режиме (`ChatStream()`).
2. При использовании fallback в стриминге токен содержал весь JSON-ответ (`{"reply":"...","corrections":[...]}`) вместо только текста reply, из-за чего JSON отображался в чат-пузыре.
3. i18n переводы не интерполировались — в JSON-файлах использовался синтаксис `{variable}` (одинарные скобки) вместо `{{variable}}` (двойные скобки), который требуется i18next.
4. Бот использовал хардкоженный production URL `https://t.me/lingvo_ai_bot/app` вместо локального `WEBAPP_URL`.
5. Chat input скрывался под NavBar на мобильных устройствах — отсутствовал padding-bottom.

## Root Cause

1. **`ChatStream()` не имел fallback** — `Chat()` (не-стриминг) уже содержал логику fallback на DeepSeek, но `ChatStream()` (SSE) при ошибке Gemini просто прекращал стрим, не вызывая `c.fallback.Generate()`.
2. **Fallback токен содержал JSON** — при вызове `c.fallback.Generate()` возвращался полный JSON-ответ. `ChatStream()` отправлял его как `EventToken` без парсинга, из-за чего интерфейс отображал JSON.
3. **Неверный i18n синтаксис** — использовался `{variable}` вместо `{{variable}}`.
4. **Хардкоженный URL бота** — `launchKeyboard()` в `handlers.go` жёстко прописывал `https://t.me/lingvo_ai_bot/app`, не читая `WEBAPP_URL`.
5. **Отсутствовал padding в Chat** — форма ввода чата находилась вне scroll-area и перекрывалась NavBar.

## Solution

1. **`internal/ai/gemini.go` — `ChatStream()`:** Добавлен fallback на `c.fallback.Generate()` при ошибке Gemini stream. Ответ fallback парсится как `AIResponse`, извлекается только `reply` для токена; полный JSON сохраняется в `fullText` для корректной работы `ParseAIResponse()`.
2. **`web/src/locales/{uz,ru}.json`:** Исправлен синтаксис интерполяции — `{variable}` → `{{variable}}` (6 ключей в каждом файле).
3. **`internal/bot/handlers.go` + `bot.go`:** `launchKeyboard()` теперь принимает `webappURL string` и передаёт его в `web_app.url` (3 call sites + 2 function signatures обновлены).
4. **`cmd/server/main.go`:** Читает `WEBAPP_URL` из env, передаёт в `bot.Start()`.
5. **`.env`:** Добавлены `DEV_MODE=true`, `WEBAPP_URL=http://localhost:5173`, `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL`.
6. **`web/src/components/Chat.tsx`:** Добавлен `paddingBottom: 'calc(var(--nav-height) + var(--safe-bottom))'` к контейнеру чата.

## Prevention

- Все стриминговые методы должны иметь fallback при ошибке первичного AI провайдера
- i18n: использовать `{{variable}}` (двойные скобки) для интерполяции в i18next/react-i18next
- URL для WebApp всегда читать из env, не хардкодить
- UI компоненты, работающие рядом с NavBar, должны учитывать `var(--nav-height)` в padding
