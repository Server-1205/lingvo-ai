# Level test button hidden behind data dependency

**Date:** 2026-06-06 19:48
**Files:** web/src/components/Progress.tsx, web/src/components/LevelTest.tsx, web/src/api/client.ts, cmd/server/main.go
**Severity:** medium

## Problem

Кнопка "Определить уровень" не появлялась в Progress-табе. Пользователь
видел только статистику, без возможности начать тест.

## Root Cause

Две причины:

1. **Progress.tsx** — кнопка была внутри блока `{progress && (...)}`, который
   рендерится только после успешного ответа от GET /api/progress. Если запрос
   не выполнился (например, из-за кэша), кнопка не появлялась.

2. **LevelTest.tsx** — использовал `fetch('/api/level', ...)` напрямую вместо
   общей функции `request()` из client.ts, поэтому запрос шёл без
   `X-Telegram-Init-Data` → 401 → ошибка.

## Solution

- Вынес кнопку из блока `{progress && ...}` в отдельный `{!isLoading && ...}`
- Заменил прямой fetch на `getLevelTestQuestions()` через общий клиент
- Добавил `getLevelTestQuestions()` в client.ts
- Добавил `Cache-Control: no-store` на все ответы сервера

## Prevention

- Кнопки действий не должны зависеть от загрузки данных
- Все API-запросы должны идти через единый клиент с initData
- При разработке UI сначала показывать все элементы, потом заполнять данными
