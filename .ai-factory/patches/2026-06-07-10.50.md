# AI language instructions, ProgressChart nil data crash, Vocab export auth

**Date:** 2026-06-07 10:50
**Files:** internal/ai/prompts.go, web/src/components/ProgressChart.tsx, web/src/components/Vocabulary.tsx, internal/api/progress.go
**Severity:** high

## Problem

1. **AI отвечает на английском** — все промпты (`BuildChatPrompt`, `BuildPremiumChatPrompt` и др.) передавали AI код языка `"uz"`/`"ru"` как `"Explain in %s"`. AI не понимает коды `uz`/`ru` как названия языков. Плюс правило 1 говорило `"Reply naturally in English"`, что конфликтовало с инструкцией о языке объяснений — AI выбирал английский.

2. **Progress вкладка — белый экран** — `ProgressChart` принимал `data` из `history.entries`. Если у пользователя нет записей прогресса, Go возвращает `{"entries": null}` (nil slice). `data.length` на `null` вызывал `TypeError: Cannot read properties of null (reading 'length')` — краш страницы.

3. **Экспорт словаря без initData** — `Vocabulary.tsx` использовал `(window as any).Telegram?.WebApp?.initData` вместо `initData.raw()` из SDK. В dev-режиме (mock Telegram) `window.Telegram` отсутствует, экспорт падает с 401.

## Root Cause

1. **Коды языков в промптах** — промпты использовали двухбуквенные коды `uz`/`ru` вместо полных названий `Uzbek`/`Russian`. Правило 1 (`Reply naturally in English`) было жёстко зашито во все чат-промпты, переопределяя инструкцию о языке объяснений.

2. **Нет защиты от nil данных** — `ProgressChart` не имел значения по умолчанию для `data`. `GetProgressHistory()` возвращает nil slice при отсутствии записей, что сериализуется в `null` в JSON.

3. **Прямой доступ к window.Telegram** — обход API клиента и Telegram SDK нарушал конвенцию проекта (все запросы через initData из SDK).

## Solution

1. **`internal/ai/prompts.go`:**
   - Добавлена функция `langFullName()`: `"uz"` → `"Uzbek"`, `"ru"` → `"Russian"`
   - Добавлен `langInstruction` map с чёткими инструкциями на родном языке пользователя
   - Убрано `"Reply naturally in English"` для uz/ru — заменено на "Always reply and explain everything in Uzbek/Russian"
   - Инструкция о языке вынесена наверх промпта (перед правилами), чтобы AI точно её видел
   - В JSON-шаблоне `"reply": "your reply in Uzbek/Russian"` — явное указание языка для reply

2. **`web/src/components/ProgressChart.tsx`:** Добавлен `data = []` — защита от null/undefined через default parameter

3. **`internal/api/progress.go`:** Добавлена проверка `if entries == nil { entries = []models.DailyProgressEntry{} }` — Go не возвращает null в JSON

4. **`web/src/components/Vocabulary.tsx`:** Заменён `window.Telegram.WebApp.initData` на `initData.raw()` из `@telegram-apps/sdk` с корректной типизацией

## Prevention

- Коды языков в AI промптах всегда маппить на полные названия (`uz` → `Uzbek`)
- Инструкция о языке ответа AI должна быть на первом месте, без противоречий
- Go слайсы, возвращаемые через JSON, проверять на nil перед отправкой: `if x == nil { x = []T{} }`
- React компоненты с пропом `data: T[]` всегда указывать default `[]` или проверять на null
- Все API-запросы должны получать initData только через SDK (`initData.raw()`), никогда через `window.Telegram`
